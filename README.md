# HD Map 查看器

基于浏览器的**高精地图（HD Map）在线查看工具**。在页面中导入 Apollo 风格的地图 `.bin` 文件后，可交互浏览车道拓扑、查看车道属性，并使用画点、画框、坐标拾取等辅助工具进行标注与测量。

> 所有解析均在浏览器本地完成，地图文件不会上传到服务器。

---

## 快速开始

### 环境要求

- 现代浏览器（Chrome、Edge、Firefox 等，需支持 ES6、`FileReader`、`SVG`）

### 启动方式

浏览器访问：https://hll-hdmap-display.vercel.app/

页面顶部状态栏显示 **「Proto 已就绪，请导入本地地图 bin 文件」** 后，即可导入地图。

### 导入地图

1. 点击工具栏 **「导入地图 (.bin)」**
2. 选择本地的 HD Map 二进制文件（扩展名 `.bin`）
3. 解析成功后，地图区域显示车道，左上角出现地图元信息面板，右侧侧栏可查看车道详情

导入失败时，状态栏与侧栏会显示具体错误信息（如 proto 未加载、文件格式错误等）。

## 地图浏览操作

| 操作               | 方式                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| **缩放**     | 鼠标滚轮（以光标位置为锚点）                                               |
| **平移**     | 左键按住拖拽                                                               |
| **旋转**     | 右键按住拖拽（绕视图中心旋转）                                             |
| **重置视图** | 点击**「重置视图」**（恢复导入后的初始缩放、平移、旋转，并重置右侧栏宽度） |

未导入地图时，缩放/平移/旋转不可用。

## 车道查看

### 选中车道

- **左键单击**地图上的车道图形
- 或在右侧搜索框输入 **车道 ID**，按 **Enter** 定位并选中

选中后：

- 当前车道高亮为**蓝色**
- **同道路**关联车道为**淡蓝色**
- **前驱**车道为**橙色**
- **后继**车道为**绿色**
- 地图上叠加显示该车道的**中心线**

点击地图空白处（非拾取坐标模式）可取消选中。

### 车道信息标签页

右侧 **「车道信息」** 区域提供四个标签：

| 标签               | 内容                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------- |
| **车道属性** | ID、类型、转向、长度、限速、左右车道线类型、路口 ID、前驱/后继/邻道、overlap 及信号灯摘要等 |
| **中心线**   | `central_curve` 各点 UTM 坐标列表                                                         |
| **车道宽度** | `left_sample` / `right_sample` 沿 s 的宽度样本                                          |
| **道路宽度** | `left_road_sample` / `right_road_sample` 沿 s 的宽度样本                                |

### 颜色图例

侧栏底部图例与地图高亮颜色一致：

- 默认车道：灰色
- 当前选中：蓝色
- 同道路车道：淡蓝
- 前驱车道：橙色
- 后继车道：绿色

### 隐藏 / 显示车道

| 操作         | 方式                                                                                    |
| ------------ | --------------------------------------------------------------------------------------- |
| 隐藏单条车道 | 在车道上**右键**打开菜单，选 **Hide**；或 **双击** 该车道（快捷方式） |
| 隐藏全部     | 侧栏**Hide all**                                                                  |
| 显示全部     | 侧栏**Show all**                                                                  |
| 清空全部标注 | 侧栏**Clear all**（清除所有画点、画框、拾取记录，不影响车道显示）                 |

隐藏的车道无法被选中；若当前选中车道被隐藏，会自动取消选中。

### 调整侧栏宽度

拖拽右侧 **「车道信息」** 面板左边缘的分隔条，宽度可自由调整。

## 标注工具（左侧工具栏）

先点击 **「画点」**、**「画框」** 或 **「坐标」** 激活工具（再次点击同一按钮可关闭）。激活后下方展开对应参数面板。

> 使用标注工具前须已导入地图。

### 坐标输入规则（画点 / 画框共用）

| 输入类型        | 判断条件                 | 字段含义                                            |
| --------------- | ------------------------ | --------------------------------------------------- |
| **UTM**   | X、Y**均大于 100** | X = 东向（Easting），Y = 北向（Northing），单位：米 |
| **WGS84** | 否则                     | X =**经度**，Y = **纬度**（度）         |

输入 WGS84 时，程序根据地图 header 中的 `proj` 字段解析 **UTM 带号（zone）** 并转换到地图坐标系后再绘制。若 proj 中无 zone 信息，会提示无法转换。

列表与状态栏中的坐标会同时显示 **UTM** 及对应的 **经纬度**（在可解析 zone 时）。

---

### 画点

1. 点击 **「画点」** 打开面板
2. 填写 **X**、**Y**（UTM 或经纬度，见上表）
3. 点击 **「绘制」**

地图上出现带标签的圆点（`P1`、`P2`…）。**已绘制** 列表中可：

- **定位**：将视图缩放到该点
- **删除**：移除单个点
- **一键删除**：清空全部点

---

### 画框（车辆轮廓）

以 **后轴中心** 为参考点，按 **航向角（弧度）** 与车宽、前轴/后轴距离绘制矩形车辆包络框。

1. 点击 **「画框」**
2. 填写后轴 **X、Y** 与 **航向角（弧度）**
3. 可选：点击 **「三方车」** 或 **「六方车」** 快速填入预设尺寸
4. 按需修改 **车宽 (m)**、**前轴 (m)**、**后轴 (m)**
5. 点击 **「绘制」**

| 预设           | 车宽 (m) | 前轴 (m) | 后轴 (m) |
| -------------- | -------- | -------- | -------- |
| 三方车         | 1.3      | 2.37     | 0.59     |
| 六方车（默认） | 1.4      | 2.95     | 0.65     |

框上显示标签 `B1`、`B2`…，中心有小圆点表示后轴位置。列表支持 **定位**、**删除**、**一键删除**。

几何说明：沿航向向前延伸 **前轴** 距离、向后延伸 **后轴** 距离，左右各 **车宽/2**，构成闭合多边形。

---

### 点击显示坐标（拾取）

1. 点击 **「坐标」** 进入拾取模式（地图区域光标样式会变化）
2. 在地图上 **左键单击** 拾取该点 UTM 坐标（记录为 `C1`、`C2`…）
3. 在 **已拾取** 列表中 **点击某条记录**（非按钮区域）可选中该点

**航向角计算：**

- 在列表中依次选中 **两个点**（最多保留 2 个选中项；选第三个会顶替最早的一个）
- 地图上显示两点间的箭头连线
- 上方结果区显示：点标签、**distance**（米）、**heading**（弧度，`atan2` 定义，从第一点指向第二点）

列表同样支持 **定位**、**删除**、**一键删除**。

> 拾取模式下，左键点击空白处会记录坐标，而不会取消车道选中逻辑与平移冲突：小幅移动仍视为点击拾取。

## 地图元信息

导入成功后，地图区域左下角显示：

| 字段               | 说明                               |
| ------------------ | ---------------------------------- |
| **文件**     | 导入的 `.bin` 文件名             |
| **地图时间** | 地图 header 中的日期/时间          |
| **UTM 时区** | 从 `header.proj` 解析的 UTM 带号 |
